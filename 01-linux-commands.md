# Linux Commands

## Basic Linux Commands

Linux commands are instructions entered into a terminal to interact with the operating system.

| #  | Command      | What it does                               | Quick summary               |
| -- | ------------ | ------------------------------------------ | --------------------------- |
| 1  | `pwd`        | Shows your current working directory       | **Where am I?**             |
| 2  | `ls`         | Lists files and folders                    | **What's here?**            |
| 3  | `cd`         | Changes to another directory               | **Move to another folder**  |
| 4  | `mkdir`      | Creates a new directory                    | **Make a folder**           |
| 5  | `touch`      | Creates a new empty file                   | **Make a file**             |
| 6  | `cp`         | Copies files or folders                    | **Make a copy**             |
| 7  | `mv`         | Moves or renames files/folders             | **Move / rename**           |
| 8  | `rm`         | Removes a file or directory                | **Delete/remove**           |
| 9  | `cat`        | Displays file contents                     | **Show the whole file**     |
| 10 | `less`       | Views file contents one screen at a time   | **View page by page**       |
| 11 | `head`       | Shows the beginning of a file              | **First 10 lines**          |
| 12 | `tail`       | Shows the end of a file                    | **Last 10 lines**           |
| 13 | `grep`       | Searches for text inside files             | **Search for text**         |
| 14 | `find`       | Searches for files and folders             | **Find files/folders**      |
| 15 | `chmod`      | Changes file/folder permissions            | **Change permissions**      |
| 16 | `chown`      | Changes the owner of a file/folder         | **Change owner**            |
| 17 | `ps`         | Shows running processes                    | **Process snapshot**        |
| 18 | `top`        | Monitors running processes and resources   | **Live process view**       |
| 19 | `kill`       | Sends a signal to a process                | **Stop/control a process**  |
| 20 | `ip`         | Views/manages network information          | **Network information**     |
| 21 | `ss`         | Shows network connections and ports        | **See connections**         |
| 22 | `curl`       | Sends requests and receives data from URLs | **Communicate with URLs**   |
| 23 | `wget`       | Downloads files from URLs                  | **Download from the web**   |
| 24 | `ping`       | Checks whether a device is reachable       | **Can I reach it?**         |
| 25 | `traceroute` | Shows the network path to a destination    | **What path does it take?** |

## Why These Commands Matter for Cybersecurity

These commands form a basic Linux foundation for cybersecurity.

They help with:

* Navigating and managing files
* Searching through files and data
* Understanding permissions and ownership
* Monitoring processes
* Inspecting network connections
* Testing network connectivity
* Working with web resources
* Troubleshooting Linux systems
